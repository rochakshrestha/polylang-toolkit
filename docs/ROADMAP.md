# Roadmap

Toolkit for Polylang is a free companion for free Polylang. Not affiliated with WP SYNTEX / Polylang. Dates are intentionally absent; order is what matters.

## Phase 1: MVP (towards 1.0)
- **DUP** Duplicate content into a new translation, with media and linked-post IDs inside blocks swapped for their translations.
- **SLUG** Translated post-type and taxonomy base slugs, and translations that share a slug, with correct hreflang, canonical and sitemap URLs.
- **SYNC** Per-field sync rules after the initial copy.
- **MEDIA** Copy title, alt, caption and description to media translations; bulk-create missing ones.
- **COMPAT** Works alongside AutoPoly, EPICWP AI, PolyTranslate AI, Yoast SEO and Rank Math.

## Phase 2
String translation management, basic XLIFF export/import, bulk translation for CPTs and taxonomies, a missing-translation report, page builder and ACF compatibility, optional machine translation with your own API key.

## Phase 3
Advanced sync rules, advanced XLIFF, workflow (assignments, notes), REST and Site Editor enhancements.

## Out of scope
DeepL integration, a WooCommerce suite, and anything that mirrors Polylang Pro's proprietary logic.
