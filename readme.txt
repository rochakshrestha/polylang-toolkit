Essential extras for free Polylang: translated slugs, content duplication, field sync and better media handling.

== Description ==

Toolkit for Polylang is a free companion plugin for the free Polylang plugin. Each feature is a module you can switch on or off; with every module off, your site behaves exactly as it does without the toolkit.

**This plugin is not affiliated with or endorsed by WP SYNTEX, the makers of Polylang.** For official premium support and advanced features, see [Polylang Pro](https://polylang.pro/). Official documentation: [polylang.pro/documentation](https://polylang.pro/documentation/).

This early version contains the foundation only: a settings page under Languages > Toolkit, a Polylang compatibility check and the module framework. Planned modules: translated URL slugs, content duplication, field synchronization, and improved media handling.

== Installation ==

1. Install and activate the free Polylang plugin.
2. Upload and activate Toolkit for Polylang.
3. Open Languages > Toolkit to switch modules on.

== Frequently Asked Questions ==

= Does it work without Polylang? =
No. It shows a notice and does nothing until free Polylang is active.

= Does it work with Polylang Pro? =
Modules that overlap with Polylang Pro stay off while Polylang Pro is active, and a notice tells you which ones.

= Is it affiliated with Polylang? =
No. It is an independent plugin. Polylang is a product of WP SYNTEX.
